# ForgeFit

Military-inspired fitness, calisthenics, nutrition and wellbeing — iOS and Android.

- 12 programs, 87 exercises, 30 meals, 8 breathing drills
- Fully offline: no account, no tracking, no ads
- 11 languages including Traditional Chinese (zh-HK)
- Light / dark / system themes
